# Schermate dell’app

Cartella permanente sul Mac per le catture condivise tra tutti i post. Puoi trascinare qui gli screenshot dall’iPhone o dal simulatore anche con il nome originale. Le immagini restano locali e sono escluse da Git. Le cartelle dei singoli post contengono le copie usate per le esportazioni.

## Cosa raccogliere

| Area | Catture da mettere qui |
|---|---|
| Home | Vista intera e sezioni sotto la piega, saldo atteso, conti, ordine, occhio, card fissi |
| Movimenti | Lista, «In arrivo», ricerca, mese/categoria, filtri avanzati, modifica, conferma ed eliminazione |
| Aggiunta | Uscita, entrata, categoria suggerita, conto, data, pianificato, spesa fissa, trasferimento |
| Ricorrenti | Lista, serie programmata/rilevata, creazione, prossima data, ambiti di modifica, salta/termina |
| Conti | Panoramica, nuovo conto, selezione tipo, inclusi/esclusi, archivia/ripristina, rettifica |
| Pianifica | Budget e Obiettivi, schermate nuove/modifica, soglie, storico, avanzamento, eliminazione |
| Statistiche | Mese, grafico 6M/12M, categorie, anteprima PDF e condivisione |
| Impostazioni e iOS | Lingua, valuta, Home, avvisi, importi nascosti, Face ID, cronologia, CSV/JSON, Comandi, widget e tocco posteriore |
| Accesso e stati | Accesso con dati fittizi, schermate vuote, versione chiara/scura, eventuali percorsi account verificati |

Per gli scatti ordinati usare, per esempio, `movimenti-filtro-categoria-it-chiaro.png`. Preferire una cattura per passaggio, schermo intero, senza notifiche e con dati fittizi coerenti. Per richieste o revisioni seguire le [direttive](../direttive-social.md).
